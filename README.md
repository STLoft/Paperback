# Paperback · 책으로 읽기

SillyTavern 채팅을 책처럼 쪽으로 나누어 넘겨 읽는 확장입니다.

## 설치

1. SillyTavern → 확장(Extensions) → **Install extension**에 이 저장소의 git 주소를 넣습니다.
2. 또는 이 폴더를 `SillyTavern/data/<사용자>/extensions/st-paperback`(또는 `public/scripts/extensions/third-party/st-paperback`)에 복사한 뒤 새로 고칩니다.

## 여는 방법

- 마법봉 메뉴 → **책으로 읽기**
- 슬래시 명령 `/book` (별칭 `/paperback`)
- 확장 설정 → *Paperback · 책으로 읽기* → **책 열기**

## 기능

- **장 나누기**: 설정의 '장 분량'에서 고릅니다.
  - `캐릭터 메시지`: 캐릭터 메시지 하나가 한 장이 됩니다.
  - `글자수`(기본): 메시지를 차례로 담다가 본문이 고른 글자수(기본 5,000자)에 이르면 다음 메시지부터 새 장을 엽니다. 아래 설명은 이 방식 기준입니다.
  - 메시지 중간에서는 자르지 않습니다. 장 분량보다 긴 메시지는 그 하나로 한 장이 됩니다.
  - 장 분량의 절반을 넘긴 뒤 `***`, `---`, `## 제목` 같은 장면 구분으로 시작하는 메시지가 오면 그 앞에서 끊습니다.
  - 첫 메시지(인사말)는 언제나 '프롤로그' 한 장입니다.
  - 위쪽 ✂ 단추(또는 N 키)로 지금 쪽의 메시지부터 직접 새 장을 열거나, 직접 나눈 장을 다시 합칠 수 있습니다.
  - 새 메시지가 와도 마지막 장만 늘어나고 지난 장은 바뀌지 않습니다.
- **쪽 나누기**: 넓은 화면에서는 두 쪽 펼침, 좁은 화면에서는 한 쪽으로 자동 전환됩니다.
  - **화면 맞춤**: 설정에서 켜면 책 둘레의 바탕 없이 종이가 화면을 가득 채웁니다. 위아래 막대는 종이 위에 겹쳐 뜨고, 가운데를 누르면 숨겨집니다.
- **넘기는 효과**: 책장 넘기기(3D) / 밀기 / 없음. 넘기는 소리는 파일 없이 Web Audio로 합성하며, 두 가지(기본·부드럽게) 가운데 고릅니다.
- **목차와 본문 검색**: 장 목록에서 바로 이동하고, 검색어가 있는 쪽으로 넘어가 강조합니다.
- **대화방 옮기기**: 목차 맨 위의 대화방 이름을 누르면 같은 캐릭터의 대화방 목록이 펼쳐집니다.
  고르면 그 대화방으로 넘어가 읽던 자리에서 책을 다시 펼칩니다.
  - 실리태번의 채팅을 실제로 바꾸는 것이라, 그 뒤에 보내는 메시지는 옮겨 간 대화방에 들어갑니다.
  - 검색란 옆의 `이 방 | 전체`로 찾는 범위를 고릅니다. `전체`는 이 캐릭터의 모든 대화방에서 찾아 대화방별로 묶어 보여 주고(방마다 3곳까지),
    누르면 그 대화방으로 넘어가 해당 글을 강조합니다.
  - 그룹 채팅에서는 대화방 줄과 범위 고르기가 나오지 않습니다.
- **책갈피**: 쪽마다 끼우고 뺄 수 있으며, 그 쪽 첫머리 글이 책갈피 이름이 됩니다.
- **읽던 위치 기억**: 다시 열면 마지막으로 읽던 쪽에서 시작합니다.
- **꾸미기**: 테마 5종(종이·하양·세피아·민트·밤), 글꼴 6종(명조·고딕·리디바탕·나눔명조·고운바탕·고운돋움),
  글자 크기·줄 간격·여백·정렬·첫 줄 들여쓰기.
  - **사용자 테마**: 테마 줄의 `+`를 누르면 지금 테마를 바탕으로 새 테마가 생깁니다.
    이름과 여섯 가지 색(바탕·종이·글자·흐린 글자·강조·대사)을 고르면 바로 반영됩니다. 여러 개 만들 수 있고 `지우기`로 없앱니다.
  - **사용자 글꼴**: 글꼴 아래 `글꼴 추가`에 글꼴 이름(font-family)과 주소를 적습니다.
    주소는 글꼴 CSS(Google Fonts 등)나 글꼴 파일(woff2·woff·ttf·otf)이고, 비워 두면 기기에 설치된 글꼴을 이름으로 찾아 씁니다.
  - 사용자 테마와 글꼴은 `기본값으로`를 눌러도 지워지지 않습니다.
- **유저 표시**: '유저 메시지'를 켰을 때 유저 글을 어떻게 보일지 고릅니다.
  `인용`(왼쪽 줄과 이름이 있는 흐린 글), `본문`(본문과 같은 모양), `대사`(대사 색).
- **내보내기**: 설정 맨 아래의 `EPUB` / `텍스트` 단추로 지금 대화방을 파일로 저장합니다.
  - 책에 보이는 대로 뽑습니다. 장 나눔, 유저 메시지 넣기와 표시 방식, 상태창 보이기 설정을 그대로 따릅니다.
  - **EPUB 꾸밈 유지**(단추 아래 스위치): 켜면 메시지 속 HTML의 `class`·`style`과 `<style>` 블록을 살려, HTML로 만든 상태창 같은 패널의 모양을 그대로 담습니다.
    끄면(기본값) 꾸밈을 걷어 내고 줄글로 뽑습니다. 전자책 앱에 따라 복잡한 배치는 다르게 보일 수 있고, 스크립트로 움직이는 것은 동작하지 않습니다.
  - EPUB에는 장 목차가 들어갑니다. '그림 보이기'가 켜져 있으면 그림도 함께 담습니다(다른 사이트가 받아 가기를 막은 그림은 빠집니다). 영상과 소리, 텍스트 파일의 그림은 넣지 않습니다.
- **기타**: 유저 메시지를 장 머리에 함께 넣기, 그림 보이기/숨기기, 마우스 휠로 넘기기.
- **상태창 보이기/숨기기**: 설정에서 끄면 상태창(인포패널)을 빼고 본문만 보여 줍니다. 채팅 원문은 바뀌지 않습니다.
  - `<Info_panel>`, `<status>`처럼 info·status·stat 계열 이름의 태그. 앞에 `이름_`이나 `이름-`이 붙은 것도 같이 걸러집니다.
  - 같은 이름의 코드블록(` ```status `)
  - class가 `info-panel`, `status-panel`, `custom-info-card` 류인 `<div>` (정규식 스크립트가 그려 낸 카드 포함)
- 책을 연 채로 새 메시지가 오거나 메시지를 고치거나 스와이프하면 책에 바로 반영됩니다.

### 책을 닫지 않고 이어 쓰기

아래 막대 오른쪽 단추들로 책을 닫지 않고 채팅을 이어 갑니다.

- **메시지 쓰기** (펜 단추, I 키): 책 아래에 입력창이 뜹니다. 실리태번 입력창과 같은 글을 쓰므로 슬래시 명령도 되고, 책을 닫아도 쓰던 글이 남습니다.
  - Enter로 보내고 Shift+Enter로 줄을 바꿉니다. 터치 기기에서는 Enter가 줄바꿈이고 보내기 단추로 보냅니다.
  - 보내면 입력창이 닫히고 새 답이 시작되는 쪽으로 넘어가며, 답이 써지는 대로 책에 나타납니다. 쓰는 동안에는 펜 단추가 멈춤 단추로 바뀝니다.
- **버전 고르기** (`‹ 2/5 ›`, [ ] 키): 펼친 쪽의 캐릭터 메시지에 다른 버전(스와이프)이 있으면 나타납니다.
  채팅의 마지막 메시지에서 마지막 버전 다음은 ↻ 로 바뀌며, 누르면 새 응답을 만듭니다.
- **고치기 · 지우기** (⋯ 단추): 펼친 쪽에 걸친 메시지 목록에서 고릅니다.
  - 고치기는 원문을 편집 창에 띄웁니다. Ctrl+Enter로 저장하고 Esc로 취소합니다.
  - 지우기는 실리태번의 확인 창을 그대로 씁니다. 버전이 여럿이면 그 버전만 지울지 메시지 전체를 지울지 고릅니다.
- 실리태번 채팅 화면에 불러오지 않은 오래된 메시지('불러올 메시지 수' 설정)는 버전 고르기와 지우기를 할 수 없습니다. 고치기는 됩니다.
- 사용자 메시지는 설정의 '유저 메시지'를 켰을 때만 책에 나오므로, 그때만 고치거나 지울 수 있습니다.

## 조작

| 동작 | 키보드 | 마우스 / 터치 |
|---|---|---|
| 다음 쪽 | → ↓ PageDown Space | 오른쪽 30% 누르기, 왼쪽으로 쓸기, 휠 아래 |
| 이전 쪽 | ← ↑ PageUp Shift+Space | 왼쪽 30% 누르기, 오른쪽으로 쓸기, 휠 위 |
| 장 처음 / 끝 | Home / End | |
| 책갈피 끼우기·빼기 | B | 위쪽 책갈피 단추 |
| 목차 | T | 위쪽 목록 단추 |
| 이 메시지부터 새 장 / 합치기 | N | 위쪽 ✂ 단추 |
| 메시지 쓰기 | I | 아래쪽 펜 단추 |
| 앞 / 다음 버전 (끝에서는 새 응답) | [ / ] | 아래쪽 ‹ › 단추 |
| 메시지 고치기·지우기 | | 아래쪽 ⋯ 단추 |
| 위아래 막대 감추기 | | 가운데 누르기 |
| 닫기 | Esc | ✕ 단추 |

## 저장 위치

- 보기 설정: `extension_settings.paperback` (SillyTavern 설정 파일)
- 읽던 위치·책갈피·직접 나눈 장: 채팅 메타데이터 `chat_metadata.paperback` (채팅 파일과 함께 저장).
  읽던 위치는 브라우저 `localStorage`에도 함께 적어 둡니다.
- 위치와 책갈피는 '메시지 + 메시지 안의 위치'로 저장하므로, 장 분량이나 글자 크기를 바꿔도 같은 글 근처로 돌아옵니다.
