# Paperback · 책으로 읽기

SillyTavern 채팅을 책처럼 쪽으로 나누어 넘겨 읽는 확장입니다.

## 설치

1. SillyTavern → 확장(Extensions) → **Install extension**에 이 저장소의 git 주소를 넣습니다.
2. 또는 이 폴더를 `SillyTavern/data/<사용자>/extensions/st-paperback`(또는 `public/scripts/extensions/third-party/st-paperback`)에 복사한 뒤 새로 고칩니다.

## 여는 방법

- 마법봉 메뉴 → **책으로 읽기**
- 슬래시 명령 `/book` (별칭 `/paperback`)
- 확장 설정 → *Paperback · 책으로 읽기* → **책 열기**

## 기능

- **장 나누기**: 메시지를 차례로 담다가 본문이 **장 분량(기본 5,000자)** 에 이르면 다음 메시지부터 새 장을 엽니다.
  - 메시지 중간에서는 자르지 않습니다. 장 분량보다 긴 메시지는 그 하나로 한 장이 됩니다.
  - 장 분량의 절반을 넘긴 뒤 `***`, `---`, `## 제목` 같은 장면 구분으로 시작하는 메시지가 오면 그 앞에서 끊습니다.
  - 첫 메시지(인사말)는 언제나 '프롤로그' 한 장입니다.
  - 위쪽 ✂ 단추(또는 N 키)로 지금 쪽의 메시지부터 직접 새 장을 열거나, 직접 나눈 장을 다시 합칠 수 있습니다.
  - 새 메시지가 와도 마지막 장만 늘어나고 지난 장은 바뀌지 않습니다.
- **쪽 나누기**: 넓은 화면에서는 두 쪽 펼침, 좁은 화면에서는 한 쪽으로 자동 전환됩니다.
- **넘기는 효과**: 책장 넘기기(3D) / 밀기 / 없음. 넘기는 소리는 파일 없이 Web Audio로 합성합니다.
- **목차와 본문 검색**: 장 목록에서 바로 이동하고, 검색어가 있는 쪽으로 넘어가 강조합니다.
- **책갈피**: 쪽마다 끼우고 뺄 수 있으며, 그 쪽 첫머리 글이 책갈피 이름이 됩니다.
- **읽던 위치 기억**: 다시 열면 마지막으로 읽던 쪽에서 시작합니다.
- **꾸미기**: 테마 5종(종이·하양·세피아·민트·밤), 글꼴 8종(시스템 명조/고딕 + Google Fonts 한글 글꼴),
  글자 크기·줄 간격·여백·정렬·첫 줄 들여쓰기.
- **기타**: 사용자 메시지를 장 머리에 함께 넣기, 그림 보이기/숨기기, 마우스 휠로 넘기기.
- 책을 연 채로 새 메시지가 오거나 메시지를 고치거나 스와이프하면 책에 바로 반영됩니다.

## 조작

| 동작 | 키보드 | 마우스 / 터치 |
|---|---|---|
| 다음 쪽 | → ↓ PageDown Space | 오른쪽 30% 누르기, 왼쪽으로 쓸기, 휠 아래 |
| 이전 쪽 | ← ↑ PageUp Shift+Space | 왼쪽 30% 누르기, 오른쪽으로 쓸기, 휠 위 |
| 장 처음 / 끝 | Home / End | |
| 책갈피 끼우기·빼기 | B | 위쪽 책갈피 단추 |
| 목차 | T | 위쪽 목록 단추 |
| 이 메시지부터 새 장 / 합치기 | N | 위쪽 ✂ 단추 |
| 위아래 막대 감추기 | | 가운데 누르기 |
| 닫기 | Esc | ✕ 단추 |

## 저장 위치

- 보기 설정: `extension_settings.paperback` (SillyTavern 설정 파일)
- 읽던 위치·책갈피·직접 나눈 장: 채팅 메타데이터 `chat_metadata.paperback` (채팅 파일과 함께 저장).
  읽던 위치는 브라우저 `localStorage`에도 함께 적어 둡니다.
- 위치와 책갈피는 '메시지 + 메시지 안의 위치'로 저장하므로, 장 분량이나 글자 크기를 바꿔도 같은 글 근처로 돌아옵니다.
